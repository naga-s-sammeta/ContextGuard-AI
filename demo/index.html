ContextGuard

One semantic map, two jobs: it narrows context so multi-table answers are accurate, and it guards every answer for certified source, freshness, approved metric, and PHI/PII before a human sees it.

Demo data is precomputed from the real DuckDB warehouse (synthetic facts; real Janssen brand names & openFDA reaction terms). Live mode swaps in a Featherless model — the same guard runs on its output.
